Acerca de StrawberryVision

Sistema de detección y clasificación de madurez de fresas basado en inteligencia artificial.

🎯 Objetivo del Proyecto

StrawberryVision es un sistema de visión por computadora diseñado para automatizar la clasificación de fresas según su estado de madurez. Utilizando redes neuronales profundas (modelo SGSNet - Strawberry Grading System Network), el sistema puede detectar y clasificar fresas en tiempo real, facilitando procesos de control de calidad y cosecha selectiva.

🛠️ Tecnologías Utilizadas

PyTorch

Framework de deep learning para el modelo SGSNet

FastAPI

Backend API moderno y de alto rendimiento

PySpark

Procesamiento distribuido para lotes grandes

OpenCV

Procesamiento de imágenes y visualización

Albumentations

Data augmentation avanzada

Chart.js

Visualización de estadísticas interactivas

📊 Características del Modelo

  • Arquitectura: SGSNet v2 Multi-escala (Feature Pyramid Network)
  • Escalas de detección: P3 (64x64), P4 (32x32), P5 (16x16)
  • Resolución de entrada: 512x512 píxeles
  • Técnicas: Soft-NMS, Mosaic Augmentation, MixUp
  • 5 clases de detección: Floración, Creciendo (verde), Creciendo (blanco), Casi maduro, Maduro
